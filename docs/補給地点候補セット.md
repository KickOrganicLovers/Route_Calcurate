# 補給地点 候補リスト

`waypoints.py` の `candidate_supply_points` の内容。この 27 件の中から最良 **7 地点** を選定する（実績拠点でも無条件採用はしない＝時間短縮を優先）。

## 選定方針（2026-09 改訂）

道の駅は **道の駅はにゅう（P4）のみ** を残し、他の道の駅は候補から除外した。含めてよいのは以下の 4 種類とする。

1. すでに候補に入っていた道の駅以外の施設（大学・東京ガス各所・環境科学国際センター等）
2. レンタルスペース（町が廃校跡地や公共機関の部屋として貸し出しているものを含む）
3. 利根川沿いの水道局等の公共施設
4. 国土交通省が管理する施設

> **除外済み**: 道の駅おがわまち、道の駅まくらがの里こが、道の駅アグリパークゆめすぎと。
> 県営浄水場（吉見・行田・庄和）も一度候補に入れたが利用不可のため取り下げ、レンタルスペースに差し替えた。

座標は住所を国土地理院ジオコーダで変換した値（利根川上流河川事務所 古河出張所のみ実測値）。`stock` は持たせない（配置台数は選定の結果として決まる）。
